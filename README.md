**Comparator** is a minimalist, zero-dependency text analysis tool built for developers and writers who need precise, noise-free difference tracking. Designed with a sharp, brutalist UI, it operates entirely client-side to ensure your data never leaves your browser.

## ✨ Features

* **Precision Diff Engine:** Utilizes a Longest Common Subsequence (LCS) algorithm to accurately highlight exact insertions (`+`) and deletions (`-`) down to the word and punctuation level.
* **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript. No build steps, no heavy frameworks, no external libraries.
* **Dynamic Routing Navbar:** Seamlessly swap layout alignments (Left, Right, Center) and mobile slide-in directions (Top, Bottom, Left, Right) simply by altering HTML classes on the `<nav>` element.
* **Native Theme System:** Built-in Light, Dark, and System preference toggling via CSS variables and `localStorage`.
* **Privacy First:** 100% client-side execution. Your sensitive text is never sent to a server.
